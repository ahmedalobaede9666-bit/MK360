# MK360 — النسخة 0.1 التجريبية

**هذه نسخة أولية للمطورين، لم تُختبر على Xbox 360 حقيقي.** نجح تجميع ملف
XEX واختبارات تحويل الإدخال وفحص بنيته؛ لا يثبت ذلك أن محمّل الجهاز أو USB
أو Call of Duty ستعمل معه. التجربة على الجهاز هي الخطوة التالية.

## المتطلبات

- Xbox 360 معدّل RGH/JTAG، بنظام **2.0.17559.0** وDashLaunch.
- قرص داخلي يظهر باسم `Hdd1:` في Aurora (`Hdd:` في إعدادات DashLaunch).
- ماوس وكيبورد سلكيان، يدعمان USB HID Boot Protocol.
- إعداد النسخة التجريبية يطلب تحميل `xbdm.xex` قبل MK360؛ تعريف HID المرجعي
  يوثّق تجمّداً بدونه. MK360 يرفض تركيب الاعتراضات عند غيابه ويسجل السبب.
  هذا الملف غير مضمّن، وليس جزءاً من سلسلة البناء المفتوحة المستخدمة هنا.
- لا تُشغّل `hiddriver360` أو `X360Remap` بالتزامن مع MK360؛ تستخدم نفس المداخل.

## التركيب الأول

1. احتفظ بنسخة من `launch.ini` الحالي لتتمكن من الرجوع إليه.
2. انسخ مجلد `MK360` الموجود في الحزمة إلى جذر القرص، ليصبح المسار:
   `Hdd1:\MK360\MK360.xex` ومعه `MK360.ini`.
3. من DashLaunch أضف `Hdd:\MK360\MK360.xex` إلى **خانة إضافات فارغة** بعد
   خانة `xbdm.xex` إن كان متوفراً عندك. احتفظ بباقي إضافاتك. ملف
   `launch.example.ini` مثال للترتيب وليس بديلاً عن ملفك الحالي.
4. احفظ إعدادات DashLaunch وأعد التشغيل والماوس والكيبورد مفصولان.
5. انتظر ظهور Aurora، ثم وصّل الماوس والكيبورد. هذه النسخة لا تعيد تشغيل
   متحكم USB ولا تستولي على جهاز سبق أن عرّفه النظام قبل تركيب اعتراضاتها.
6. اقرأ `Hdd1:\MK360\MK360.log`. يتحدث كل خمس ثوانٍ. المطلوب مبدئياً:
   `phase=running_experimental` و`keyboards=1` و`mice=1`، وعدّاد `usb_reports`
   يزيد عند الحركة أو الضغط. `player_index=0` يعني اللاعب الأول؛ `255` يعني
   أن اليد الافتراضية لم تُسجّل. افصل يد التحكم الحقيقية قبل أول اختبار لتجنب
   حجزها خانة اللاعب الأول.
7. افتح إحدى ألعاب Call of Duty من Aurora. اختر توزيع يد التحكم **Default**
   وأوقف عكس النظر العمودي داخل اللعبة. ابدأ بحساسية مرتفعة داخل اللعبة
   ثم اضبط حساسية MK360 تدريجياً. لا توجد معايرة مثبتة لأي إصدار COD بعد.

ملف `MK360.xex` **إضافة نظام**؛ تحميله يكون من DashLaunch، وليس كتطبيق
واجهة مستقل من Aurora. لا تحتاج إلى إبقاء شاشة برنامج مفتوحة. التصميم
يستخدم خيط نظام وذاكرة إضافة، ويعيد تسجيل اليد عند انتقال عنوان اللعبة.
استمرار ذلك على الجهاز ينتظر التحقق العملي.

## الأزرار الافتراضية لـ Call of Duty

| الإدخال | يد Xbox 360 | الوظيفة المعتادة مع توزيع Default |
|---|---|---|
| W / A / S / D | العصا اليسرى | الحركة |
| تحريك الماوس | العصا اليمنى | النظر والتصويب |
| الزر الأيسر للماوس | RT | إطلاق |
| الزر الأيمن للماوس | LT | تصويب ADS |
| Space | A | قفز |
| C أو Ctrl الأيسر | B | انحناء |
| R أو F | X | إعادة تلقيم / استعمال |
| 1 | Y | تبديل السلاح |
| Shift الأيسر | ضغط العصا اليسرى | ركض |
| V أو الزر الأوسط للماوس | ضغط العصا اليمنى | اشتباك قريب |
| Q / E | LB / RB | القنابل بحسب اللعبة |
| Enter أو Esc | Start | القائمة |
| Tab | Back | لوحة النتائج بحسب اللعبة |
| الأسهم | D-pad | اتجاهات |

قد تختلف وظائف أزرار اللعبة بحسب الجزء والإعدادات؛ MK360 يرسل أزرار يد التحكم.

## الضبط أثناء اللعب

- **F6:** تشغيل / إيقاف التحويل؛ عند إيقافه يُرسل وضعاً محايداً.
- **F7 / F8:** خفض / رفع الحساسية بمقدار 50. التعديل مؤقت للجلسة الحالية.
- **F9:** إعادة قراءة `MK360.ini` بعد تعديله وإعادته إلى الجهاز. القيم غير
  الصحيحة تُرفض ويبقى الإعداد السابق، ويُسجل رقم السطر الخاطئ.

`ads_percent` نسبة حساسية الماوس عند إرسال LT، و`smoothing` مقدار التنعيم
من 0 إلى 90. `deadzone_x` و`deadzone_y` تعويض لمنطقة الخمول من 0 إلى 30000؛
ابدأ بالقيم المرفقة ثم عدّل بعد اختبار الحركة البطيئة في لعبتك.

لكل لعبة إعداد مستقل اختياري: انسخ قيمة `title_id` من السجل وضعها بين قوسين
مربعين في الملف، ثم اكتب القيم المختلفة تحتها. قسم `[default]` هو الأساس.
مثال توضيحي (استبدل المعرّف بمعرّف لعبتك):

```ini
[1234ABCD]
sensitivity=800
ads_percent=55
```

يمكن تعديل `bind_SPACE=A` وغيرها. الأهداف: `A B X Y LB RB LT RT LS RS
START BACK UP DOWN LEFT RIGHT MOVE_UP MOVE_DOWN MOVE_LEFT MOVE_RIGHT NONE`.
الكيبورد يدعم أسماء الحروف والأرقام والأسماء الموجودة في المثال؛ F6–F9 محجوزة.

## حدود هذه النسخة

- ثلاثة أزرار للماوس وحركة X/Y بصيغة boot ذات 8 بت؛ عجلة التمرير والأزرار
  الإضافية وNKRO والبروتوكولات الخاصة غير مدعومة حالياً. كون الجهاز سلكياً
  وحده لا يكفي لضمان توافقه.
- تعريف USB يستخدم عناوين خاصة بالنظام 17559. يفحص الإصدار وبعض التعليمات
  قبل التعديل، ويرفض المداخل التي تغيرت أو التي سبق اعتراضها.
- معالجة الفصل ما زالت تجريبية: تُوقف الإدخال وتحتفظ بذاكرة الجلسة حتى إعادة
  التشغيل، لتفادي تحرير ذاكرة نقل USB جارٍ. لا ندّعي اكتمال إلغاء النقل
  وتنظيف نقاط النهاية. توجد ثماني جلسات فقط حتى إعادة التشغيل؛ تجنّب
  تكرار الفصل وإعادة التوصيل خلال الاختبار الأول.
- الصورة ثابتة عند `0x81F00000`، دون جدول إعادة تموضع. قد يرفضها المحمّل إذا
  كان العنوان مستخدماً من إضافة أخرى. إقرار محمّل Xbox بصيغة DLL هذه غير مختبر.
- لا توجد واجهة رسومية أو معايرة خاصة بكل محرك لعبة. التحويل إلى العصا يبقى
  مقيداً بسرعة دوران اللعبة، ولا ندّعي دقة أو معايرة XIM4.

## التشخيص والرجوع

| السجل | المعنى |
|---|---|
| `xbdm_required` | إضافة xbdm غير محمّلة قبل MK360؛ لم تُركّب الاعتراضات |
| `unsupported_kernel` | النظام ليس 17559 |
| `hook_init_failed` | عدم تطابق مدخل أو تعارض إضافة أو رفض تعديل الذاكرة |
| `bypassed` | درج الأقراص مفتوح عند تهيئة MK360؛ تجاوز التشغيل |
| `running_experimental` مع صفر أجهزة | لم يصل جهاز boot HID إلى التعريف؛ جرّب التوصيل بعد ظهور Aurora |

إذا ظهر تجمّد، أعد تشغيل الجهاز مع تجاوز الإضافات بالطريقة المتاحة في
إعداد DashLaunch لديك، واحذف خانة MK360 من `launch.ini`. تجاوز درج الأقراص
الموجود في MK360 يعمل فقط بعد نجاح تحميل DLL ووصول التنفيذ إلى خيطه؛ لا
يحل فشل تحميل الصورة نفسها. لا تُفرغ الإضافة من الذاكرة أثناء عمل USB.

للمراجعة بعد الاختبار أرسل `MK360.log` واسم جزء Call of Duty وتحديثه،
وموديل الماوس والكيبورد، وما إذا ظهرت المشكلة قبل فتح اللعبة أم بعدها.
لا يحتاج السجل إلى كلمات مرور أو مفاتيح الجهاز أو معلومات حساب Xbox.
