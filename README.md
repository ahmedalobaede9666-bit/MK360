# MK360

مساعد ماوس وكيبورد سلكيين على Xbox 360 المعدّل، يعمل كإضافة DashLaunch بصيغة XEX.

**قيد التطوير — لم يُختبر على جهاز حقيقي بعد.** يجري إعداد أداة بناء مفتوحة المصدر،
وقارئ USB HID، وتحويل الإدخال إلى يد تحكم مع إعداد أولي لألعاب Call of Duty.

لا يحتاج المشروع إلى Xbox 360 XDK. سلسلة الأدوات مبنية من GCC وbinutils مع
تصحيحات ABI من [xsdk](https://github.com/xenosworks/xsdk).
